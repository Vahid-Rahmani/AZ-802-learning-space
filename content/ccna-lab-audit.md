## 3. Source manifest

Sources are Cisco IOS/IOS XE configuration guides, Cisco command references, the official
200-301 v1.1 exam topics PDF, Cisco Networking Academy / Packet Tracer material, IETF RFCs
(RFC 1918, 3927, 4291, 8200 and the OSPF/DHCP/DNS/NAT set) and Cisco developer documentation
for REST/JSON objectives. All are publicly available; no exam dumps, paid-course text or
copied lab prose is used, and every scenario and explanation is original.

Each source reference is stored as `{ key, title, url, covers, section, checked, confidence }`,
with `checked: 2026-10-08`. `confidence` is `reviewed` where the exact section/command could
be pinned down, and the lab is marked `needs-review` where it could not.

## 7. Limitations and remaining work

- `npm run lint` reports one `react-hooks/set-state-in-effect` error in
  `app/components/ccna-practice.tsx`. That file is **not part of this change set**
  (`git diff` is empty) and the identical error is produced by the committed HEAD revision,
  verified by linting `git show HEAD:app/components/ccna-practice.tsx` — it is pre-existing.
- Screenshot capture was unavailable in this session (the preview webview produced no
  frames), so sign-off is based on DOM geometry and interaction assertions, not pixels.
- Real device or provider acceptance is not claimed: the labs run in the learner's own
  Packet Tracer or simulator, and the site records self-reported practical outcomes.
- To exercise the account-gated flow locally, the built worker needs a session secret: a
  `SESSION_SECRET` of 32+ characters in `dist/server/.dev.vars` (the value used is the one already
  published in `lib/auth-config.ts` as the local-development fallback). `dist/` is gitignored and
  regenerated by `npm run build`.
- Five catalog labs publish no topology diagram in the source catalog; their cards say so
  explicitly instead of showing a placeholder image.

Limitations of this slice, stated plainly:

- The local **production** build cannot authenticate: `lib/auth-config.ts` returns the development
  secret only when `NODE_ENV !== "production"`, so the built Worker answers `AUTH_NOT_CONFIGURED`
  (503). The interactive check above therefore ran on the development server (`npm run dev`,
  `http://localhost:5173`). The production bundle itself built and served `/ccna/sim` with HTTP 200.
- S0 ships no lab pack, topology, objective or grading: those are slices S1–S3 in the plan, and the
  page states that instead of implying more.
- The earlier session console buffer still holds the pre-existing `te is not a function` RSC prefetch
  error from a production `/ccna` visit; it predates this slice and is not produced by this page.
